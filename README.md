# 코트 콜 — 테니스 리모컨 MVP

Flutter Android / iOS 앱. 서버·리시버 득점, 게임 자동 종료, 한국어 음성 안내.

## 실행

```powershell
cd C:\Users\kimjh0417\work_space\tenis
flutter pub get
flutter emulators --launch Pixel_9a

flutter run -d emulator-5554
```

장치 ID는 `flutter devices` 결과로 교체합니다. 화면 버튼 또는 PC 키보드 **↑ / ↓ / Enter**로 테스트합니다. 한국어 음성이 없으면 Android 설정의 텍스트 음성 변환에서 한국어 음성 데이터를 설치하세요.

Mac에서는 `flutter pub get` 후 `ios/Runner.xcworkspace`를 Xcode에서 열어 Signing Team과 고유 Bundle ID를 설정하고 iPhone에서 `flutter run` 합니다. Windows에서는 iOS 빌드/서명/시뮬레이터 실행이 불가능합니다. 기본 앱 ID와 Android 디버그 서명은 로컬 테스트용입니다.

## 득점 규칙

- 위: **현재 서버** +1. 아래: **현재 리시버** +1.
- 0 → 15 → 30 → 40 → 게임. 듀스에서는 두 점 차로 승리.
- 게임 승리 시 승자의 게임 수 +1, 포인트 0:0, 서버 교대.
- 게임 수는 선수 A/B에 고정됩니다. 화면 포인트는 항상 서버가 왼쪽입니다.
- 가운데: 40:30, 30:40, 어드밴티지에서 앞선 선수 득점. 그 외(듀스 포함)는 현재 점수 안내.
- 위→아래→위→위→위: 15:0 → 15:15 → 30:15 → 40:15 → A 게임 1:0, 포인트 0:0. 다음 위 입력은 B 득점.
- 새 경기: 이름·첫 서버 설정. 되돌리기: 최근 100점, 게임/서버 변경도 복원.
- 점수·설정·되돌리기 기록 로컬 저장. 로그인/서버 없음.
- 일반 게임 누적 MVP. 세트 종료, 타이브레이크, 복식 서브 순서는 제외.

## SOBTR1 실물 검증 (미완료)

휴대폰 Bluetooth 설정에서 페어링 → 앱 **리모컨 버튼 등록** → 위/아래/가운데 각각 등록 → 패널을 닫고 경기 시작.

현재 `HardwareKeyboard` 키 입력만 지원합니다. 세 버튼이 서로 다른 키 신호를 보내야 합니다. 키 반복·해제는 득점하지 않습니다. 중복 키는 등록 거부하며 15초 내 신호가 없으면 안내합니다. 등록 중·새 경기 대화상자·일시 정지에는 득점하지 않습니다.

**실제 SOBTR1 전송 방식은 확인하지 못했습니다.** 화면 스와이프/터치/볼륨 전용 신호라면 현재 구현으로 동작하지 않을 수 있습니다. 에뮬레이터 검증은 실물 호환성을 보장하지 않습니다. 연결 상태는 휴대폰 설정에서 확인합니다.

전경 실행만 지원합니다. 자동 화면 잠금을 방지하지만 수동 잠금/다른 앱 전환 후 입력은 지원 범위 밖입니다. TTS 실패는 화면에 표시하고 득점은 유지합니다.
